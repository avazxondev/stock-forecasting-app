# 📈 Stock & Crypto Trend & Volatility Forecasting Dashboard

> A powerful, end-to-end Data Science web application built with Python, Streamlit, and Meta Prophet to forecast asset trends and analyze market volatility in real-time.

## 🛠️ Tech Stack & Libraries
* **Python** (Core programming)
* **Streamlit** (Interactive Web UI)
* **Pandas & NumPy** (Data manipulation & mathematical operations)
* **Plotly** (Interactive data visualization)
* **Meta Prophet** (Time series forecasting model)
* **yfinance** (Real-time financial data fetching)

---

## ✨ Key Features
1. **Real-Time Data Integration:** Automatically fetches historical and current market data for any stock (e.g., AAPL, TSLA) or crypto (BTC-USD, ETH-USD) via Yahoo Finance API.
2. **Mathematical Indicators & Risk Analysis:** Computes Simple Moving Averages (SMA 50, SMA 200) and annualized rolling volatility (standard deviation).
3. **Machine Learning Forecasting:** Uses Meta Prophet time series forecasting to predict future price trends with upper and lower confidence intervals.
4. **Interactive Dashboard:** Dynamic user controls to adjust prediction periods and tickers instantly.
